拾材 2.3.0 / macOS 安装说明

选择与你的 Mac 处理器一致的安装包：Apple Silicon 用 arm64，Intel 用 x64。
请先完整解压 ZIP，再运行“安装拾材.command”；脚本将应用放入你的 ~/Applications，并在存在桌面目录时创建快捷方式。已有应用会备份，不会清理个人资料。

这个安装包是在 Windows 上装配的，保留了官方 Mac 运行时的文件执行权限与符号链接。当前已完成压缩包、程序架构、应用版本、文件哈希和链接结构检查，但还没有在真实 Mac 上启动验收。

完整解压后，双击“安装拾材.command”。脚本会先在临时目录中复制与本机签名、验证，再安装；任何检查失败都不会替换原应用。安装完成后按回车打开拾材。

此包没有 Apple Developer ID 签名或公证。首次打开可能需要你按 macOS 的正常提示批准；它不会关闭系统保护或修改系统安全设置。如系统提示无法打开，请参照 Apple 官方说明：https://support.apple.com/zh-cn/102445
