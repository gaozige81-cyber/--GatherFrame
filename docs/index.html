第一次打开，做这三件事。

01

找一组图片

在“寻找图片”输入关键词；也可以从“搜图网站”进入你熟悉的图库。

在软件“偏好设置 → 软件更新”填入发布地址，勾选启动时自动检查并保存。也可以使用“检查更新”按钮。发现新版后由你下载和安装。

你可能想知道

用之前，
先了解一下。

需要注册拾材账号吗？＋

不需要。头像、姓名、收藏、收集箱和任务记录保存在本机，可通过备份导出和迁移。AI 网站与 API 使用你自己的平台账号。

图片会上传到服务器吗？＋

图片格式转换在本机执行，不会为了转换上传图片。在线搜图需要向来源网站发送关键词；AI API 模式则会按你的操作调用对应服务。

AI 海报助手可以免费生图吗？＋

拾材没有内置付费密钥或无限免费生图服务。官网模式帮你整理提示词、打开官方页面，是否免费由该平台的账户权益决定。API 模式需要自行配置密钥与额度，接口适配尚未逐个平台进行真实付费账户验收。

转换会保留动图、图层和原始元数据吗？＋

转换输出为 8 位静态图片。GIF/APNG 通常取首帧，TIFF 取第一页；不保留原始 EXIF、ICC 配置或分层。SVG 输出是位图嵌入，不是矢量描摹。检测透明像素也不等于自动抠图。

这里就是网页版拾材吗？＋

这里是拾材的介绍与下载网站。完整工作台请下载桌面版使用，在线搜图和 AI 服务的可用性取决于你的网络及来源平台。
